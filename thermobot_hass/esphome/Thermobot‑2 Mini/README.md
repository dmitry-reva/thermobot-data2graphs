# Thermobot‑2 Mini — конфигурации ESPHome

В этом каталоге находятся конфигурации ESPHome для платы **Thermobot‑2 Mini**
на ESP8266. Основной сценарий — измерение подачи и обратки отопительного
контура двумя датчиками DS18B20 с передачей данных в Home Assistant.

Если нужна общая информация о подключении и прошивке Thermobot‑2, см.
основной [README ESPHome](../README.MD).

## Какую конфигурацию выбрать

| Файл | Назначение | Когда использовать |
|---|---|---|
| [heatflow.yaml](heatflow.yaml) | HeatFlow: измерение подачи и обратки, разницы температур, калибровка и независимые пороги тревоги | Основная и рекомендуемая конфигурация для использования с Home Assistant |
| [thermobot-ds.yaml](thermobot-ds.yaml) | Реконструкция функций заводской прошивки по анализу дампа: один DS18B20, настройки и уведомления Telegram, дисплей и физическая кнопка | Если нужно сохранить сценарий, близкий к заводскому |
| [thermobot-cc.yaml](thermobot-cc.yaml) | Альтернативная, более ранняя реконструкция заводской прошивки | Для справки и сравнения; перед использованием проверьте совместимость с установленной ESPHome |
| [secrets.example.yaml](secrets.example.yaml) | Пример общих секретов и секретов Telegram | Скопируйте в `secrets.yaml` перед сборкой |
| [different.md](different.md) | Подробное сравнение `thermobot-ds.yaml` и `thermobot-cc.yaml` | Для выбора между реконструкциями заводской прошивки |

`heatflow.yaml` — отдельная пользовательская прошивка, а не реконструкция
заводской прошивки. Для подробностей о функциях и статусе проверки см.
комментарии в начале соответствующего YAML и раздел Thermobot‑2 Mini в
[основной документации ESPHome](../README.MD).

## Возможности HeatFlow

- Измерение температур подачи и обратки датчиками DS18B20 на общей шине 1‑Wire.
- Отдельная калибровка и нижний/верхний пороги тревоги для каждого датчика.
- Сущность разницы температур: подача минус обратка.
- Оповещение о выходе за пороги и отказе датчика; тревогу можно подтвердить
  кнопкой в Home Assistant. Физическая кнопка на GPIO14 необязательна.
- Настройка звукового сигнала, светодиода и параметров тревоги из Home Assistant
  или web-интерфейса.
- ESPHome API с шифрованием, OTA и аварийная точка доступа Wi‑Fi.

## Подготовка секретов

Скопируйте [secrets.example.yaml](secrets.example.yaml) в `secrets.yaml`
в этом каталоге и задайте собственные значения. Для `heatflow.yaml` нужны:

```yaml
wifi_0f: "имя_сети_2.4GHz"
wifi_password: "пароль_wifi"
web_server_pass: "пароль_web-интерфейса"
api_key: "ключ_шифрования_api"
```

Имя `wifi_0f` намеренное: оно должно совпадать с `!secret wifi_0f`
в конфигурации. Не переименовывайте его в `wifi_ssid`.

Для `thermobot-ds.yaml` добавьте `tg_token` и `tg_chat` из примера. Для
`thermobot-cc.yaml` используются другие имена Wi‑Fi-секретов (`wifi_ssid`);
конфигурации также может понадобиться `ota_password`. Сверьте полный список
с комментариями в выбранном YAML.

Не добавляйте `secrets.yaml` в git: файл с секретами не предназначен для
публикации.

## Адреса DS18B20

В `heatflow.yaml` укажите реальные уникальные адреса датчиков в подстановках
`addr_supply` и `addr_return`. Адреса-заглушки из примера нужно заменить.
Узнайте адреса по логам ESPHome; чтобы установить, какой адрес относится к
какому датчику, подключайте датчики по одному. Подробная инструкция есть в
разделе [«Адреса датчиков DS18B20»](../README.MD#адреса-датчиков-ds18b20).

Для `thermobot-ds.yaml` адрес DS18B20 также следует проверить и при необходимости
заменить согласно комментариям конфигурации.

## Проверка и сборка

Запустите команды из этого каталога, где находятся YAML и `secrets.yaml`:

```console
esphome config heatflow.yaml
esphome compile heatflow.yaml
```

При выборе другой конфигурации замените `heatflow.yaml` в командах на её имя.
Перед прошивкой проверьте, что выбраны правильная конфигурация, адреса датчиков
и секреты. Первую прошивку через USB‑UART и дальнейшее обновление описывает
[основной README ESPHome](../README.MD).

## Подключение

| Пин | Назначение |
|---|---|
| GPIO0 | Шина 1‑Wire DS18B20; требуется подтяжка 4,7 кОм к 3,3 В |
| GPIO2 | Светодиод, инверсная логика |
| GPIO12 | Пассивный зуммер |
| GPIO14 | Опциональная кнопка подтверждения тревоги |

Для полной схемы платы см. [схему пинов Thermobot‑2 Mini](../images/PINOUT-MINI2.JPG).
