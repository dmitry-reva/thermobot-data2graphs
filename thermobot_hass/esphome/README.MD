# Thermobot‑2 Mini — ESPHome‑мониторинг температуры

Конфигурация для платы **Thermobot‑2 Mini** ([42unita.ru]) под задачи контроля температур в отопительных системах. Проект ориентирован на простое развёртывание и гибкую настройку.

## Что делает устройство

- Считывает температуру с датчиков Dallas DS18B20 через one‑wire на GPIO0.
- Показывает статус работы с помощью светодиода на GPIO2.
- Передаёт в Home Assistant температуру подачи, обратки и (опционально) третьего датчика.
- Формирует понятный аптайм (дни/часы/минуты).
- Подаёт визуальный сигнал (мигание светодиода) при успешном подключении к Wi‑Fi.

## Аппаратная часть

- **Плата:** Thermobot‑2 Mini.
- **Производитель:** [42unita.ru](https://www.42unita.ru).
- **Датчики:** DS18B20 (one‑wire).
- **Индикатор:** светодиод на GPIO2 (поддерживается инверсная логика).
