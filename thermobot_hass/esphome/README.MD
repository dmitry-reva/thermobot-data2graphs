# Thermobot‑2 Mini — ESPHome‑мониторинг температуры в Home Assistant

Конфигурация для платы [**Thermobot‑2 Mini**](Thermobot‑2%20Mini/heatflow.yaml) под задачи контроля температур в отопительных системах. Проект ориентирован на *почти простое* развёртывание и гибкую настройку.

## Что делает устройство

### Назначение устройства

Устройство предназначено для измерения температуры с помощью датчиков DS18B20 (контроль подачи и обратки), включает следующие функции:

- **Измерение температуры** с возможностью ручной калибровки показаний.
- **Индикация состояния** посредством светодиода.
- **Wi‑Fi‑подключение** с обработкой этапов загрузки и установки соединения.
- **Оповещения** — звуковые и визуальные.
- **Сигнализация по температуре** при выходе за установленные пороги (минимальный и максимальный): срабатывает повторяющийся звуковой сигнал на зуммере.

---

### Датчики

- Используемый датчик: Dallas DS18B20 (интерфейс 1‑Wire).
- Подключение: к GPIO0.
- Количество датчиков: опционально (можно подключить несколько).

---

### Выходные интерфейсы

- **Светодиод**: подключён к GPIO2 — используется для индикации состояния устройства.
- **Пассивный зуммер**: подключён к GPIO12, управление через программный ШИМ (PWM).  
  Поддерживается настройка:
  - громкости сигнала;
  - частоты звучания;
  - длительности сигнала.

---

### Входные интерфейсы

- **Кнопка**: подключена к GPIO14.  
  Является опциональной — если кнопка не установлена, соответствующий блок логики можно исключить из прошивки.


## Аппаратная часть

- **Плата:** Thermobot‑2 Mini с ESP8266MOD (4Mb).
- **Производитель:** [42unita.ru](https://www.42unita.ru).
- **Датчики:** DS18B20 (one‑wire). В оригинале от производителя смонтирован один, под проект без изменения схемы подключения параллельно добавлен еще один. Адреса датчиков уникальные, актуальные можно узнать из логов устройства в ESPHome, первоначально указать в YAML 0x0000000000000000, потом заменить на актульный. 
- **Индикатор:** светодиод с инверсной логикой, пискун.
- **Прошивка:** с адаптером USB‑UART на базе CH340G.

## Программная часть

- **Создание прошивки** ESPHome для ESP8266MOD (4Mb) осуществляется с помощью файла [heatflow.yaml](Thermobot‑2%20Mini/heatflow.yaml) и завершается  скомпилированным firmware.bin.
- **Прошивка проекта** локально с помощью esptool через адаптер USB‑UART.
- **Web-интерфейс** доступен в новой прошивке по адресу mDNS в локальной сети: [heatflow.local](http://heatflow.local), либо IP.
- **Home Assistant** получит новое устройство через стандартную интеграцию ESPhome.

## Прошивка (случай автора)

![подключение Thermobot‑2 Mini через адаптер USB‑UART для первой прошивки](images/write-bin.jpeg)


*Рисунок: Подключение Thermobot‑2 Mini локально через адаптер USB‑UART для первой прошивки*

Команда для прошивки ESP8266 в командной строке Windows:

```CLI
(venv) C:\esp\...\venv\Scripts>esptool --chip esp8266 --port COM4 --baud 115200 write-flash --flash-mode qio --flash-size 4MB 0x00000 firmware.bin
```


**Важные моменты:**
- usb type-c для прошивки **не используется!**, порт использовать только для питания прошитого устройства;
- плату к USB‑UART подключать по питанию 3,3В;
- для входа в режим прошивки: при подключении платы, *заземлить* GND к GPIO0, потом GND к RST, *отключить* GND от RST, потом GND от GPIO0; 
- заменить COM4 на актуальный COM‑порт вашего устройства;
- файл firmware.bin должен находиться в текущей рабочей директории esptool, либо использовать venv, либо полный путь к файлу;
- вариантов способов прошивки несколько, приведен тот, который точно работает у автора.

## Настройка

### Секреты

Скопируйте `secrets.example.yaml` в `secrets.yaml` и заполните значения:

```yaml
wifi_0f: "ssid_вашей_сети_2.4GHz"
wifi_password: "пароль_вашей_сети_2.4GHz"
web_server_pass: "пароль_для_веб_интерфейса"
api_key: "api_ключ_для_home_assistant"
```

`secrets.yaml` исключён в корневом `.gitignore` и не должен попадать в git.
