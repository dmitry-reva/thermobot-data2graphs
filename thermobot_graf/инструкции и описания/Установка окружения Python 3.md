1.  **Установите Python 3**, если он ещё не установлен на вашей системе.
    Обычно это можно сделать с помощью пакетного менеджера вашей
    операционной системы:

    - для Ubuntu/Debian: sudo apt update && sudo apt install python3;

2.  **Создайте директорию**, если она ещё не существует:

3.  sudo mkdir -p /opt/thermobot_graf/

4.  **Перейдите в созданную директорию**:

5.  cd /opt/thermobot_graf/

6.  **Создайте виртуальное окружение** (рекомендуется для изоляции
    зависимостей проекта):

7.  python3 -m venv venv

Здесь venv --- название директории, где будет храниться окружение.

8.  **Активируйте виртуальное окружение**:

9.  source venv/bin/activate

После активации в начале строки командной оболочки появится (venv),
указывающее на активное окружение.

10. **Установите необходимые пакеты** из файла requirements.txt (если он
    у вас есть):

11. pip install -r requirements.txt

В вашем случае файл requirements.txt содержит следующие зависимости:

DateTime==6.0

narwhals==2.15.0

numpy==2.4.0

packaging==25.0

pandas==2.3.3

plotly==6.5.1

python-dateutil==2.9.0.post0

pytz==2025.2

six==1.17.0

tzdata==2025.3

zope.interface==8.2

12. **Проверьте установленные пакеты**, выполнив:

13. pip list

Убедитесь, что все необходимые библиотеки установлены в нужных версиях.
