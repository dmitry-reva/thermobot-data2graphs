Данный скрипт представляет собой **юнит-файл systemd** (.timer), который
настраивает периодический запуск сервиса thermobot.service с заданными
интервалами.

**Разбор секций скрипта**

1.  **\[Unit\]**

    - Description=Timer for Thermobot Graf (starts after 60 min) ---
      краткое описание таймера: он связан с проектом «Thermobot Graf» и
      предполагает запуск через 60 минут (хотя в секции \[Timer\]
      указаны другие значения).

2.  **\[Timer\]**

    - OnBootSec=20min --- таймер запустит сервис thermobot.service через
      **20 минут после загрузки системы**.

    - OnUnitInactiveSec=20min --- после завершения (или остановки)
      сервиса thermobot.service, таймер снова активируется и запустит
      его **через 20 минут**.

    - Unit=thermobot.service --- указывает на сервис, который будет
      запускаться по расписанию. Таймер привязан к юнит‑файлу
      thermobot.service.

3.  **\[Install\]**

    - WantedBy=timers.target --- означает, что таймер будет активирован
      при загрузке системы, поскольку он «желателен» (wanted) для
      целевой группы timers.target в systemd.

Инструкция по установке thermobot.timer

**Шаг 1. Сохраните юнит-файл**

Сохраните содержимое скрипта в файл с именем thermobot.timer в
директории /etc/systemd/system/:

sudo nano /etc/systemd/system/thermobot.timer

Вставьте текст скрипта и сохраните файл (в редакторе nano --- нажмите
Ctrl+O, введите имя файла, затем Enter).

**Шаг 2. Проверьте корректность файла**

Убедитесь, что файл записан без ошибок, выполнив:

systemctl validate /etc/systemd/system/thermobot.timer

Если ошибок нет, команда не выведет сообщений.

**Шаг 3. Перезагрузите конфигурацию systemd**

Чтобы systemd распознал новый юнит, выполните:

sudo systemctl daemon-reload

**Шаг 4. Активируйте таймер**

Включите таймер для автоматического запуска:

sudo systemctl enable thermobot.timer

**Шаг 5. Запустите таймер**

Активируйте таймер вручную (если требуется немедленный эффект):

sudo systemctl start thermobot.timer

**Шаг 6. Проверьте статус таймера**

Убедитесь, что таймер работает корректно:

sudo systemctl status thermobot.timer

В выводе должно быть указано, что таймер активен (active (waiting) или
аналогичный статус).

Также можно посмотреть список активных таймеров:

systemctl list-timers \--all

**Шаг 7. Проверьте логи (при необходимости)**

Если таймер не срабатывает, изучите логи:

journalctl -u thermobot.timer -b -n 50

Флаг -b показывает логи с момента последней загрузки, -n 50 ---
последние 50 записей.

**Важные замечания**

- **Убедитесь, что сервис thermobot.service уже настроен и
  работоспособен.** Таймер зависит от него, и если сервис не
  сконфигурирован, таймер не сможет его запустить.

- Проверьте права доступа и корректность путей в обоих юнит‑файлах
  (thermobot.service и thermobot.timer).

- Если сервис долго выполняется, интервал между запусками может
  сдвигаться. Следите за временем работы thermobot.service.

- Для отладки удобно временно отключать таймер:

- sudo systemctl disable thermobot.timer \# отключить автозагрузку

- sudo systemctl stop thermobot.timer \# остановить таймер
