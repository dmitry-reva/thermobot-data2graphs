Скрипт написан на языке **Python 3** и предназначен для сбора данных о
температуре из лог‑файлов термоботов, построения графика с помощью
библиотеки **Plotly** и сохранения результата в виде **HTML‑страницы** с
автоматическим обновлением.

**Основные функции скрипта**

1.  **Сбор данных из логов**\
    Скрипт ищет файлы по шаблону \*.log в директории
    /var/log/thermobot_logs/, считывает их содержимое и извлекает пары
    «временная метка --- температура».

2.  **Парсинг данных**\
    Для каждой строки лога:

    - строка разбивается по символу \| на две части: временную метку и
      значение температуры;

    - временная метка преобразуется в объект datetime;

    - значение температуры очищается от символов (например, °C) и
      конвертируется в число с плавающей точкой;

    - некорректные строки пропускаются с выводом сообщения об ошибке.

3.  **Объединение и сортировка данных**\
    Все извлечённые данные объединяются в единый DataFrame (с помощью
    pandas), после чего сортируются по времени.

4.  **Построение графика**\
    Используется библиотека **Plotly**:

    - для каждого исходного лог‑файла создаётся отдельная линия на
      графике;

    - каждая линия имеет свою легенду (имя файла‑источника);

    - настраиваются оси, заголовок, всплывающие подсказки
      (hovertemplate) с форматированием времени и температуры;

    - добавляется селектор диапазона времени (1 час, 6 часов, 1 день,
      весь период).

5.  **Сохранение результата**\
    График сохраняется в HTML‑файл
    /opt/thermobot_graf/temperature_dashboard.html с включением Plotly
    JS из CDN.

6.  **Автообновление страницы**\
    В HTML‑код добавляется мета‑тег \<meta http-equiv=\"refresh\"
    content=\"62\"\>, который заставляет страницу обновляться каждые
    **62 секунды**.

**Ключевые параметры**

- LOG_DIR = \"/var/log/thermobot_logs/\" --- директория с лог‑файлами
  термоботов.

- OUTPUT_DIR = \"/opt/thermobot_graf\" --- директория для сохранения
  итогового HTML‑файла.

- OUTPUT_HTML --- полный путь к итоговому файлу
  (/opt/thermobot_graf/temperature_dashboard.html).

- FILE_PATTERN = os.path.join(LOG_DIR, \"\*.log\") --- шаблон поиска
  лог‑файлов.

**Используемые библиотеки**

- os --- работа с файловой системой;

- pandas (pd) --- обработка и агрегация данных;

- plotly.graph_objects (go) и plotly.subplots --- построение
  интерактивного графика;

- datetime --- работа со временем;

- glob --- поиск файлов по шаблону.

**Обработка ошибок**

Скрипт включает защиту от следующих ситуаций:

- отсутствие подходящих лог‑файлов (вывод сообщения и завершение с кодом
  1);

- некорректный формат строки в логе (пропуск строки с выводом
  предупреждения);

- ошибки при чтении или парсинге файлов (вывод сообщения с указанием
  файла и ошибки).

**Вывод в консоль**

Скрипт сообщает:

- сколько файлов найдено для обработки;

- об ошибках парсинга или чтения файлов;

- путь к сохранённому HTML‑файлу после успешного завершения.

**Итог**

В результате работы скрипта формируется **интерактивная HTML‑страница с
графиком температур**, которая:

- отображает данные из всех доступных логов термоботов;

- группирует данные по исходным файлам;

- позволяет выбирать временной диапазон;

- автоматически обновляется каждые 62 секунды.
